# IT Midterm: Hotel Room Reservation Tracker

 ## Overview

This Java desktop app manages Hotel Room Reservation. It allows users to reserve rooms, process guest check-ins and check-outs, and view available rooms. The system uses  a custom data structure to organize and manage room reservation records efficiently without using "java.util" collections.

## Features

*Add Reservation: Adds a guest's name, reservation ID, and room details to the system.
